Avoir le script sur maya :

1. Télécharger le dossier `Atelier_8` depuis GitHub.
2. Placer le dossier dans un emplacement accessible sur l'ordinateur.
3. Ouvrir Maya.
4. Afficher le Shelf dans Maya.
5. Créer une nouvelle catégorie (Shelf) et lui attribuer un nom.
6. Ouvrir le fichier `Atelier8.py` dans le dossier `Atelier_8`.
7. Copier le code du script.
8. Dans Maya, ouvrir Windows → General Editors → Script Editor.
9. Aller dans l'onglet Python et coller le code.
10. Sélectionner tout le code, puis maintenir le clic sur le bouton du milieu de la souris (molette) et faire glisser le code vers le Shelf.





Le bouton est maintenant créé et le script peut être lancé directement depuis le Shelf.






Maintenant, pour changer l'icone du script :

1. Faire un clic droit sur le bouton du script dans le Shelf.
2. Sélectionner Edit ou Edit Shelf Button.
3. Dans la fenêtre de configuration, repérer la section Icon Label
4. Repérer le champ Icon.
5. Cliquer sur le bouton de sélection de fichier et choisir l'image souhaitée.
6. Confirmer les modifications.

Et voila ! L'icone apparait dans le shelf !
